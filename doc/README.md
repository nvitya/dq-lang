# Historical DQ Design Archive

The maintained and published documentation lives in [`docs/`](../docs/).
Nothing under `doc/archive/` is authoritative for the current compiler.

The archive contains:

- [`original-specification/`](archive/original-specification/), the initial
  monolithic language draft and its changelog;
- [`work-notes/`](archive/work-notes/), later specifications, implementation
  plans, and design discussions used while features were developed.

Use the published [coverage inventory](../docs/090-appendices/050-documentation-coverage.md)
to find the maintained replacement for every archived document. Corrections to
current behavior belong in `docs/` and relevant autotests, not in this archive.

The [previous site sources](docs-v1/) are retained as a migration snapshot.
The maintained book's coverage inventory maps their replacement chapters.
