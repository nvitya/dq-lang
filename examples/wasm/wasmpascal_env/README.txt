wasmpascal standalone app
=========================

This folder is a complete, self-contained web app compiled from a Pascal
program by the wasmpascal IDE (Download menu -> "Standalone app (.zip)").
Host it on any static web server — upload the whole folder, then visit
index.html. (The program is a separate .wasm file the runner page loads, so
it needs HTTP; the "Standalone app (.html)" export is the single-file
version that opens straight from disk.) No build step, no dependencies, no
compiler required: the program's compiled WebAssembly is the .wasm file.

Files
-----
  index.html            the runner page (boots the program)
  runtime-core.js       core host runtime: DOM setup, wasm loader, error handling
  runtime-console.js    console runtime (included for console/text programs)
  runtime-canvas.js     canvas runtime (included for basic_canvas programs)
  runtime-batchiness.js batchiness runtime & audio synth (for batchiness games)
  runtime-pascaldom.js  pascaldom runtime (for pascaldom programs)
  worker.js             console run-worker (included for console programs when SAB is used)
  pascaldom.js          DOM bridge (included for pascaldom programs)
  batchiness.js         canvas bridge (included for batchiness programs)
  <program>.wasm        the compiled program

Which programs does it run?
--------------------------
All of them:

  - Canvas programs (pascaldom / batchiness / basic_canvas ABIs) run on any
    static host, no headers required. Keyboard, mouse, audio and the canvas
    all work.
  - Console programs (write/writeln/read/readln/TextColor/GotoXY/...) work on
    any static host. read/readln prompt with the browser's input dialog, and
    Delay(ms) is a no-op. A console program whose main body loops forever
    (e.g. the console Breakout game) will freeze the page in this mode.

For the FULL console experience — inline readln input bar, Delay(ms) game
pacing, ReadKey/KeyPressed, and infinite game loops — serve the page with
cross-origin isolation headers (this unlocks SharedArrayBuffer for the
worker):

    Cross-Origin-Opener-Policy:   same-origin
    Cross-Origin-Embedder-Policy: require-corp

nginx example:

    location /your-app/ {
        add_header Cross-Origin-Opener-Policy   same-origin;
        add_header Cross-Origin-Embedder-Policy require-corp;
    }

Netlify: put these lines in a _headers file. GitHub Pages cannot set custom
headers, so console games there use the fallback mode above.

Controls
--------
  Restart   reloads and re-runs the program
  readln    type into the input bar (isolated mode) and press Enter
