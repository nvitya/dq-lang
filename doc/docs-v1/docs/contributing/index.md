# Contributor Documentation

These pages explain how the compiler and documentation are maintained. They are
public for transparency but are not part of the DQ language contract.

- [Documentation Policy](documentation-policy.md) defines authority, status,
  review, and archival rules.
- [Coverage Inventory](coverage-inventory.md) maps every former specification to
  its current destination.
- [Module and Interface Internals](module-and-interface-internals.md) describes
  the current `.o`/`.dqm_if` implementation.
- [Exceptions and Backtraces](exceptions-and-backtraces.md) outlines the hosted
  runtime implementation.
- [Release and Cross-Build Notes](release-and-cross-builds.md) collects
  maintainer-only build procedures.
- [Writing Current DQ](writing-current-dq.md) is a compact checklist for humans
  and AI agents producing repository code.

Proposals and historical design documents remain in the repository archive.
They may be useful context, but must not be cited as implemented behavior.
