# Standard Packages

The runtime and standard packages ship as DQ source. Begin with the
[Library Overview](010-library-overview-and-sys.md) for imports and package discovery.

- [`sys`](015-sys.md): implicit runtime services, memory, and process arguments.
- [`print`](020-print.md): console output.
- [`strutils`](030-strutils.md): formatting, searching, and text helpers.
- [`file`](040-file.md): files, directories, and paths.
- [`json`](050-json.md): JSON trees, parsing, and serialization.
- [`threads`](060-threads.md): native threads, atomics, and channels.
- [`time`](065-time.md): timestamps, elapsed time, date formatting, and sleeps.
- [`nanonet`](070-nanonet.md): sockets and HTTP servers.
- [`shell`](075-shell.md): child processes, captured output, and environment variables.
- [Additional Standard Packages](080-additional-standard-packages.md): math,
  parsing, database bindings, and lower-level platform interfaces.
